Privacy Policy

Last updated: November 16, 2026

Hipo! Uploader uses YouTube API Services. This policy explains what data the tool handles.

Data we access

The tool requests these Google OAuth scopes, only on the account that owns the channel Hipo! (@Hipoteti_Camente):

  • youtube.upload: to upload videos that the owner generated.
  • youtube.readonly: to list the owner's own uploaded videos (title, publish date, duration, public view/like/comment counts).
  • yt-analytics.readonly: to read aggregate, anonymous statistics of the owner's own videos (views, watch time, average view percentage, audience retention, likes, shares, subscribers gained).

The tool does not read comments' content, subscriber lists, or any data about individual viewers, and it does not access any other channel.

Data we store

We store an OAuth refresh token for the owner's own account, as an encrypted secret in the owner's private GitHub repository, and the aggregate statistics of the owner's own videos in that same private repository, to decide which videos work best. These statistics contain no personal data about viewers. The owner can delete them at any time by removing the files from the repository. We do not collect, store or share any personal data of other YouTube users or visitors, and we do not use cookies or analytics on this site.

Sharing

We do not sell, share or transfer data to third parties.

Google user data

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube API Services is also governed by the Google Privacy Policy.

Revoking access

You can revoke the tool's access at any time at https://myaccount.google.com/permissions, as described in Google's security settings. After revocation, the stored token stops working and is deleted by the owner.
