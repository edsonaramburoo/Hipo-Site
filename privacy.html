Privacy Policy

Last updated: November 2026

Hipo! Uploader uses YouTube API Services. This policy explains what data the tool handles.

Data we access

The tool requests the Google OAuth scope youtube.upload on the account that owns the channel Hipo! (@Hipoteti_Camente), only to upload videos that the owner generated. It does not read the channel's other data, comments, analytics or subscribers.

Data we store

We store only an OAuth refresh token for the owner's own account, as an encrypted secret in the owner's private GitHub repository. We do not collect, store or share any personal data of other YouTube users or visitors, and we do not use cookies or analytics on this site.

Sharing

We do not sell, share or transfer data to third parties.

Google user data

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube API Services is also governed by the Google Privacy Policy.

Revoking access

You can revoke the tool's access at any time at https://myaccount.google.com/permissions, as described in Google's security settings. After revocation, the stored token stops working and is deleted by the owner.
